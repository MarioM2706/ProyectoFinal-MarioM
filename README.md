# Proyecto Final Servidor

    Mario Martinez Goethyn 2º DAW.

## Descripción:
    Este proyecto consiste en Crear una aplicación web en PHP para gestionar de forma eficiente los pedidos de un
    restaurante de estilo McDonald’s. En esta aplicación, el cliente hace su pedido desde el móvil
    y los camareros se encargan de servir lo solicitado. La aplicacion estara conectada a una base de datos y habran 3 roles,
    que son:
    - Cliente: consulta la carta del restaurante y hace su pedido. Si después del primer
    pedido quiere añadir más productos, puede hacerlo como una nueva ronda, igual que
    en un restaurante tradicional. Una vez confirmada una ronda y enviada a cocina, no
    se puede modificar: solo se pueden añadir nuevas rondas a la misma cuenta.

    - Camarero: sirve los productos y marca cada uno como servido. Además, cuando los
    clientes han pagado, marca la mesa como pagada para liberarla y que otros clientes
    puedan usarla, también marcan la mesa como ocupada.

    - Encargado: corrige los errores de las cuentas (modificando o eliminando productos),
    gestiona las categorías, los productos de la carta y el stock, y consulta los informes.
    Además, puede dar de alta nuevos camareros y encargados, y bloquear usuarios
    (clientes, camareros o encargados) cuando sea necesario.

## Como iniciarlo:
    Para iniciar este proyecto, debes seguir estos pasos:
        1. Tener instalado XAMPP (En caso de que no lo tengas, instalalo).
        2. Descargar la carpeta comprimida del Repositorio.
        3. Descomprimir la carpeta.
        4. Guardar La carpeta descomprimida del repositorio en la carpeta htdocs de XAMPP.
        5. Iniciar XAMPP y activar "Apache" y "mysql".
        6. Escribir en la url del navegador "localhost/" seguido de la ruta donde este la carpeta del repositorio en htdocs.
        7. Una vez dentro del proyecto, registrate o inicia sesion si ya estas registrado.
        8. ¡Ya puedes usar la app!
